# Open Duck Mini v2 build

Everything for this build lives in this folder.

| Path | What it is |
|---|---|
| **Tracker** — http://localhost:8430 | Print and shopping progress, the assembled 3D model and colour planning. It starts at login; there's also a "Duck Build Tracker" entry in the app menu. |
| `print/` | The 36 printable STLs. This is a shortcut to `official_repo/print`, so there's only one copy. Open them in Orca from here. |
| `print/mods/` | Community mods from upstream (Jaime's v2 mods, Justin's head mod). Optional. |
| `official_repo/` | The official GitHub repo (`apirrone/Open_Duck_Mini`, branch `v2`), unmodified. It holds the docs (`docs/print_guide.md`, `docs/assembly_guide.md`, wiring diagrams) and the robot model used by the 3D view. Update it with `git -C official_repo pull`. |
| `tracker/` | The tracker app. Your progress is saved in `tracker/data/progress.json`, and the previous save is kept as `progress.json.bak`. |
| `tracker/data/catalog.json` | The part and shopping catalogue, generated by `tracker/tools/build_catalog.py`. |
| `tracker/data/sourcing_2026-09-26.json` | Canadian sources for every item to buy (best pick plus an alternate). Links, prices and stock were checked on 2026-09-26. To refresh, edit it (or add a newer file) and run `python3 tracker/tools/build_catalog.py tracker/data/sourcing_2026-09-26.json`. |
| `archive/` | Superseded notes from the earlier agent (Hermes, 2026-09-23). Kept for reference; the tracker's shopping list replaces them. |

## Print settings (official guide)
All parts are PLA at 15% infill. The two foot soles (`foot_bottom_tpu.stl`) are TPU at 40% infill.
There are 51 pieces in total: 44 structural and 7 optional "expression" pieces (eyes, bulb, flashlight, speaker mounts).

## Things to know
- **Servos:** you need 14 × Feetech STS3215, and they must be the **7.4 V** (19 kg·cm) version.
- **Bearing:** you need 3 × **6804** (20 × 32 × 7 mm), measured from the CAD model. Hermes's old list had F623ZZ, which is wrong.
- **Screws:** the upstream guide doesn't give exact counts. You need M3 heat-set inserts, M3×6 and M3×10 screws (an M3 assortment covers it), and blue Loctite 243 for metal-into-servo screws. Don't use Loctite on the plastic screws.
- **Guides:** assembly is at https://tnkr.ai/explore/docs/open-duck-mini/open-duck-mini-v2, and the CAD is linked from `official_repo/README.md`.

## Duck Puppet (was the tracker), http://localhost:8430
Pose, hold, record and replay the real duck's 14 servos (2026-10-22). The page talks to
`tracker/duck_agent.py` running on the duck's Pi (deployed and started by the page's
"Connect duck" button over ssh, HTTP :8091 on the Pi). Clips are saved in
`tracker/data/clips/*.json` as `[[seconds, {joint: radians}], ...]` in the runtime and
simulator frame. The old build tracker is still at http://localhost:8430/build/.
Do not run the agent and the walk program at the same time: both need the servo adapter.
```
systemctl --user status duck-tracker     # is it running?
systemctl --user restart duck-tracker
# The service runs with --lan: open http://192.168.50.109:8430 from any device on the home network
ssh bdxv2@bdxv2.local 'tail ~/duck_agent.log'    # the agent on the Pi
```
